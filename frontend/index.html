05

词牌与宫调库

十七宫调 · 调式与情感　（引自元·燕南芝庵《唱论》）
技术路线　旋律音高序列 → Krumhansl 音级轮廓调性判定 → 隐马尔可夫模型（观测：每小节音级加权直方图；状态：调内和弦）→ 维特比算法全局最优解码 → 风格化音型编排 → 多振荡器实时合成。导出使用标准 MIDI 文件格式（SMF）与 16bit PCM WAV 编码。
文字配乐　文本 → 断句与格律指纹 → 词牌匹配（字数 / 句数 / 句式三重比对）→ 宫调推定 → 依字行腔（声调走向 + 韵脚落音 + 乐句动机）→ 写入节奏网格 → 复用同一条和声与伴奏流水线。
说明　本页为纯前端静态原型，音高识别、和弦推导、文本配乐与音频合成都由浏览器实时完成，可离线运行。后续可将和弦模块平移至 Python 服务端，对齐教材 4.4 的 B/S 架构。
